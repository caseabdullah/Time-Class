# ⏰ Custom Time Class Using C++ | Time Management & Formatting

## 📌 About the Project

This project implements a custom **Time class in C++** to manage time using hours, minutes, and seconds.

It provides time validation, time setting and increment operations, and multiple time formatting options, including 12-hour and 24-hour formats.

## 🛠️ Technologies & Concepts

- **Language:** C++
- **Concepts Used:**
  - Object-Oriented Programming (OOP)
  - Encapsulation
  - Constructors
  - Getters and Setters
  - Time Validation
  - Time Increment Operations
  - Output Formatting
  - `iomanip` Library

## ⚙️ Implemented Features

### 1. Time Construction & Management
- Default Constructor
- Parameterized Constructor
- Set Hour
- Set Minute
- Set Second
- Set Complete Time
- Get Hour
- Get Minute
- Get Second

### 2. Time Increment Operations
- Increment Seconds
- Increment Minutes
- Increment Hours
- Support Custom Increment Values
- Handle Carry Forward Between Seconds, Minutes, and Hours

### 3. Time Formatting
- Print Time in 12-Hour Format (AM/PM)
- Print Time in 24-Hour Format
- Display Time Using Formatted Output

## 🧠 Key Learning Outcomes

- Understanding class design and encapsulation.
- Managing time using hours, minutes, and seconds.
- Implementing time validation.
- Understanding increment and carry-forward logic.
- Working with default and parameterized constructors.
- Using getters and setters.
- Formatting output using `iomanip`.
- Understanding 12-hour and 24-hour time representations.
